板块1：教育学基础与教育家

教育的概念与基本要素 P1

"教育"一词最早来自《孟子·尽心上》"得天下英才而教育之"。广义教育含家庭、社会、学校教育；狭义指学校教育。基本三要素：教育者（主导）、受教育者（主体）、教育影响/中介（内容+手段）。

教育的本质属性 P0

教育是有目的地培养人的社会活动。三层内涵：①育人性——人类特有；②目的性——有意识有计划；③社会性——社会交往中发生。选择题看到"有目的培养人的社会活动"直接选；有"动物"直接排除。

口诀：育人性、目的性、社会性
动物学技能不是教育；偶然无计划的活动不是教育；个人闭门自学不是教育。

教育的起源学说 P0

  • 神话起源说：最古老，代表朱熹，错误
  • 生物起源说：第一个正式提出，利托尔诺、沛西·能。教育源于动物生存本能。缺陷：抹杀社会性
  • 心理起源说：孟禄（谐音梦露）。儿童对成人无意识模仿。缺陷：忽视主观能动性
  • 劳动起源说：主流学说，米丁斯基、凯洛夫。劳动过程中经验传递
口诀：生理劳神；生物"C罗专升本本(本能)"；心理"美梦驱心魔"；劳动"腹肌男劳动"。看到"正式提出"选生物；"主流学说"选劳动。

教育的社会属性 P1

  • 永恒性：人在教育在
  • 历史性：古今不同
  • 历史继承性：古今相同
  • 相对独立性：与政治经济发展不平衡、有历史继承性、有质的规定性
  • 长期性、生产性
口诀：永立相

教育的功能 P1

  • 按对象：个体功能（本体）vs社会功能（派生）
  • 按性质：正向（积极）vs负向（消极，如应试教育）
  • 按呈现形式：显性（计划性为标志）vs隐性（非预期）

中国/外国古代教育史与教育特征 P2

  • 中国：夏朝庠序校；西周六艺（学在官府=阶级性）；稷下学宫；隋唐六学二馆（等级性）；宋元书院
  • 外国：古埃及以僧为师以吏为师；古印度以《吠陀》为内容；雅典崇文（和谐发展教育）；斯巴达尚武
  • 古代教育特征=专门机构+阶级性等级性+与生产劳动相脱离；近代=国家化义务化；现代=民主化终身化全民化现代化多元化
口诀：现代"民众权限多"（民主/终身/全民/现代/多元）

孔子 P0

《论语》。核心：①教育对象有教无类；②教育目的学而优则仕；③庶富教；④教学内容六经；⑤教学方法因材施教（"求也退故进之，由也兼人故退之"）、启发诱导（"不愤不启，不悱不发"——世界最早启发式）、学思行并重；⑥德育以仁礼为核心孝悌为基础；⑦教师：学而不厌诲人不倦。

口诀：有因启学（有教无类/因材施教/启发诱导/学思结合）
孔子=中国最早启发式；苏格拉底=西方最早启发式（产婆术）。

《学记》 P0

《礼记》一篇，乐正克所作。世界最早教育专著。名句：①"道而弗牵，强而弗抑，开而弗达"——启发诱导；②"学不躐等""不陵节而施"——循序渐进；③长善救失；④教学相长；⑤"建国君民教学为先""化民成俗其必由学"——社会作用；⑥"玉不琢不成器"——个人作用；⑦未发先豫/及时施教/学习观摩/藏息相辅。

口诀：启发→循序渐进→长善救失→教学相长
《学记》=世界最早（中国）；昆体良《雄辩术原理》=西方最早教育著作。

苏格拉底·柏拉图·亚里士多德·昆体良 P1

人物著作核心观点地位
苏格拉底—产婆术（问答法）西方最早启发式教学
柏拉图《理想国》寓学习于游戏最早提出
亚里士多德《论灵魂》《政治学》首次提出教育遵循自然—
昆体良《雄辩术原理》—西方最早教育著作，世界第一部研究教学法著作，班级授课制萌芽

培根·夸美纽斯·洛克·卢梭·康德·裴斯泰洛齐 P0

  • 培根：首次提出教育学应独立
  • 夸美纽斯《大教学论》：教育学之父，近代第一本教育学著作，泛智教育（"把一切事物教给一切人"），系统论述班级授课制，教育适应自然，教师"太阳底下最光辉职业"。《母育学校》=西方第一本学前教育学著作
  • 洛克《教育漫话》：白板说+绅士教育，外铄论
  • 卢梭《爱弥儿》：自然主义教育，内发论，个人本位论
  • 康德：最早在大学讲授教育学，教育万能论
  • 裴斯泰洛齐：慈爱的儿童之父，最早提出教育心理学化，最早将教育与生产劳动结合付诸实践
口诀：培根"首提出"；夸美纽斯"击垮大毒贩/夸父追日照亮所有人"（班级授课/大教学论/独立/泛智）；洛克"漫画身板/白洛克"（漫话/绅士/白板）；卢梭"不自爱"（自然/爱弥儿）；康德"首讲授"；裴斯泰洛齐"很心动"（心理学化/生产劳动）
夸美纽斯=近代教育学之父；赫尔巴特=现代教育学之父。

赫尔巴特 P0

《普通教育学》=教育学正式独立标志（现代第一本）。现代/科学教育学之父。①一原则：教育性教学；②二基础：伦理学+心理学；③三中心（传统）：教师中心、教材中心、课堂中心；④四段教学：明了→联想→系统→方法。实质教育论，学科中心，社会本位论。

口诀："一二三四、原理中断"；赫=科=科学研究教育→现代教育学之父

杜威 P0

《民主主义与教育》，实用主义。①四个即：教育即生活/教育即生长/教育即经验改造/学校即社会；②教育无目的论；③新三中心：学生中心、经验中心、活动中心；④从做中学；⑤五步教学法。活动中心课程论，设计教学法首创，生活本位论。

口诀："既无民主，不做儿童"；杜=度=新的一种度法→新三中心
杜威=教育适应生活说；斯宾塞=教育准备生活说。

斯宾塞 P1

《教育论》。科学知识最有价值。教育准备生活说。《什么知识最有价值》提出"课程"一词。实质教育论，学科中心。

口诀："在边塞学论语"（斯宾塞/科学/预备生活）

板块2：教育本质·起源与社会发展

教育与生产力（经济） P1

生产力制约教育：①决定教育规模和速度；②制约人才培养规格和教育结构；③制约教学内容方法手段；④制约教学组织形式。

教育经济功能：①再生产劳动力（基本途径）；②再生产科学知识（重要途径）；③促进技术创新；④带来人力资本收益（舒尔茨）。

口诀：生产力"龟速人手"；经济功能"老科技/劳科产人"

教育与政治经济制度 P0

政治经济制度制约：①决定领导权；②决定受教育权；③决定教育目的性质；④影响教育内容和制度。

教育政治功能：①培养政治人才/完成政治社会化；②制造社会舆论；③促进政治民主化；④促进政治社会化。

口诀：制约"瘦0泪目/领受性内"；政治功能"社会人煮鱼/人政社民"
政治经济制度决定内容和目的；文化只影响内容和目的。生产力决定规模速度。

教育与文化、人口 P1

文化功能：①传递保存（纵向）；②传播交流（横向）；③选择提升（推陈）；④更新创造（出新）。文化对教育作用=影响价值取向/环境/内容方法管理体制/目的。

人口功能：控制增长/提高素质/影响迁移/优化结构。

口诀：文化功能"笛声焦躁/传播选新"；文化作用"假装泪目"

个体身心发展一般规律 P0

规律含义教育启示
顺序性低级到高级、量变到质变，不可逆循序渐进，不拔苗助长
阶段性不同年龄不同特征和矛盾分阶段教学，不一刀切
不平衡性同一方面不同速，不同方面不同步，有关键期适时而教，抓关键期
互补性某方面受损可通过其他方面补偿长善救失、扬长避短
个别差异性个体间存在差异因材施教
口诀："边骑平衡车边嘘嘘，插进湖里摔断了"；顺阶不互差

影响人身心发展的因素 P0

  • 遗传：生理前提/物质基础，提供可能性，有可塑性，不起决定作用
  • 环境：现实基础，将可能性转化为现实
  • 学校教育：起主导作用
  • 主观能动性：从可能转向现实的决定性因素/动力
口诀："传经教主/遗环学主"
遗传不能决定发展；学校教育主导而非决定；主观能动性才是决定因素。

内发论与外铄论 P1

理论核心代表人物
内发论靠遗传和天性，成熟机制决定孟子（性善）、弗洛伊德、格塞尔（双子爬梯）、霍尔（一两遗传胜一吨教育）、卢梭、高尔顿、威尔逊
外铄论靠环境和教育荀子（性恶）、洛克（白板说）、华生（一打婴儿）

教育万能论：爱尔维修提出。

口诀：内发"内个孟获说高德威武"；外铄"外甥巡逻/外寻落花"

20世纪以后教育特征 P1

①全民化；②民主化；③多元化；④现代化；⑤终身化。

口诀：全民多现身/"民众权限多"
板块3：教育目的与全面发展教育

教育目的概述与层次结构 P0

层次：国家教育目的→学校培养目标（具体化）→学科课程目标→教师教学目标（进一步具体化）。功能=激励/导向/调控/评价。理论依据=马克思关于人的全面发展学说（教育与生产劳动结合是根本途径）。

口诀：层次"教培咳血"；功能"李导控评"；社人全

教育目的理论 P1

理论代表人物
社会本位论孔德、赫尔巴特、柏拉图、涂尔干、荀子、凯兴斯泰纳
个人本位论洛克、卢梭、罗杰斯、福禄贝尔、裴斯泰洛齐
生活本位论斯宾塞（预备生活）、杜威（教育即生活）
教育无目的论杜威
口诀：社会本位"社孔赫图涂荀凯兴"；个人本位"克人梭杰伦福禄齐"

全面发展教育构成 P0

  • 德育：灵魂、统帅、方向，首要地位
  • 智育：认知基础/前提支持
  • 体育：物质基础/物质保证，根本任务=增强体质
  • 美育：动力
  • 劳育：综合体现

五育相互依存相互促进，德育为先。全面发展≠平均发展≠均衡发展。

口诀："灵前勿动盒/德魂智基体物质美动力劳综合"

美育与素质教育 P1

美育=发现美/感受美/鉴赏美/表现美/创造美。内容=艺术美/自然美/社会美/科学美（艺术教育最主要）。原则=形象性/情感性/差异性/创造性/活动性。途径=各科教学和课外文艺/大自然/社会日常生活。

素质教育：以提高国民素质为根本宗旨；创新精神实践能力为重点；面向全体；全面发展；促进个性。

口诀：美育"发现受捡肥皂"；原则"性感易闯祸"；素质教育"提速'创屎'体面的歌星"

义务教育特征 P1

强制性（最本质/最基本）、普及性、免费性（另有公共性、基础性）。免费=只免学杂费，书本费不一定全免。

口诀："强扑免费公鸡"

我国教育目的基本精神与教育方针 P0

①坚持社会主义方向性；②坚持全面发展；③培养独立个性；④教育与生产劳动相结合（根本途径）；⑤提高全民族素质（根本宗旨）。教育方针：为社会主义现代化服务、为人民服务，与生产劳动和社会实践结合，培养德智体美劳全面发展的社会主义建设者和接班人。

板块6：教学理论

教学概念与意义 P1

教学=教育目的规范下教师教与学生学共同组成的活动。教学与教育=部分与整体（基本途径）；与智育=交叉；与上课=整体与部分（上课是中心环节）。教学首要任务=双基（基础知识+基本技能）。

口诀：意义"中戏面基"；任务"德智体美及格"

教学过程本质与四大规律 P0

特殊认识过程：引导性/间接性/教育性/简捷性。

  • ①间接经验与直接经验统一（间接性规律）：以间接经验为主，以直接经验为基础
  • ②掌握知识与发展能力统一（发展性规律）：知识≠能力，不完全同步
  • ③教师主导与学生主体统一（双边性规律）：主导主要标志=调动学生积极性
  • ④传授知识与思想教育统一（教育性规律）：教学永远具有教育性

结构：激发动机（起始）→领会知识（中心，理解教材是中心）→巩固→运用→检查。

口诀：特殊性"引荐个御姐认识认识"；规律"失血过多截肢不能穿黑丝"；结构"罚0攻孕检"
辨析坑：只需间接经验→错；知识越多能力越强→错；教师主导=老师说了算→错；只教知识不教品德→错。

八大教学原则 P0

  • 科学性与思想性统一：既教书又育人
  • 理论联系实际：书本联系生活
  • 直观性：实物/模象/语言直观
  • 启发性：调动主动性，引导独立思考——中学核心原则（材料题万能）
  • 循序渐进：由浅入深，不陵节而施
  • 巩固性：及时复习
  • 因材施教：分层教学
  • 量力性（可接受性）：难度适合，不拔苗助长
口诀："科理直启循巩因量/关公有实力从不见财起意"；直观"直女不要选择御姐"；启发"黄赌毒住墓地"；循序渐进"细男人"
材料题：不直接给答案让思考→启发性；图片模型→直观性；分层→因材施教；难度适中→量力性。

常用教学方法 P0

  • 直观感知：演示法（教师操作）、参观法
  • 实际训练：练习法、实验法（学生操作）、实习作业法（与所学相关）、实践活动法（与所学无关）
  • 情感陶冶：欣赏教学法、情境教学法
演示法=教师做，实验法=学生做。老师做实验=演示法，学生做=实验法。

教学工作五大基本环节 P1

  • 学业成绩检查与评价

教学组织形式 P1

班级授课制（夸美纽斯1632首次论述，我国1862京师同文馆最早，最基本形式）。辅助=个别辅导/现场教学；特殊=复式教学。其他：分组教学/设计教学法（杜威首创克伯屈推广）/道尔顿制（帕克赫斯特）/特朗普制/导生制/翻转课堂。

优点：效率高/系统性强/发挥教师主导。缺点：难因材施教/不利学生主体性实践。

口诀：优点"大面积收集倒卖纸吸管"；缺点"见财起意"

口诀："金晨安抚劫匪"

注意的分类与品质 P0

分类：无意注意（无目的不努力）/有意注意（有目的需努力）/有意后注意（有目的不努力，如熟练打字）。

品质：广度（一目十行）/稳定性（含起伏=正常）/分配（边听课边记笔记）/转移（主动切换）。

口诀：品质"转粉广汽"；培养"抬去吸点粪"
分散=被动消极（走神）；转移=主动积极。起伏=正常生理。有意后注意≠无意注意。

感觉与知觉 P0

感觉现象：适应/对比/后像/补偿/联觉（一种刺激引起多种感受，如"甜蜜的声音"）。感受性=能力，感觉阈限=量（反比）。

知觉四大特性：选择性（从背景选对象）/整体性（部分组整体）/理解性（用经验解释）/恒常性（条件变知觉不变）。

社会知觉偏差：首因/近因/刻板（对一类人）/晕轮（对一个人）/投射（以己度人）。

口诀：感觉"性能限量/事后对补联"；知觉"尝姐体香/选整理恒"
感觉=个别属性；知觉=整体属性。刻板=对一类人；晕轮=对一个人。

记忆分类与过程 P0

  • 瞬时记忆：0.25~2秒，容量大
  • 短时记忆：约20秒（<1分钟），7±2组块，意识清晰，操作性强
  • 长时记忆：永久，容量无限

瞬时→短时经注意；短时→长时经复述。过程=识记→保持→回忆与再认（回忆=简答；再认=选择）。

口诀：短时特点"昨晚两具干尸复活"

遗忘理论与艾宾浩斯曲线 P0

理论：衰退说/干扰说（主流，前摄抑制=先对后，倒摄抑制=后对先）/压抑说（弗洛伊德）/提取失败说/同化说（奥苏贝尔）。

艾宾浩斯：遗忘立即开始，先快后慢、先多后少。要及时复习，过度学习150%（即50%）效果最优。

口诀：衰干压同；先快后慢及时复习过度学习150%；影响因素"往情人房间尿尿"

①及时复习；②分散优于集中；③阅读与尝试回忆结合；④多感官协同；⑤精加工/记忆术；⑥合理分配时间；⑦组块化/多重编码；⑧过度学习150%。

口诀："及分尝感术配/集分长感运配"；提高记忆"公主驸马异地"；组织复习"异常太多过分分"

思维与创造性 P0

分类：动作/形象/抽象逻辑（中学主导）；聚合vs发散。创造性三特征=流畅性（数量多）/变通性（角度多）/独创性（新颖）。

思维定式=习惯旧方法，双面（方法上）；功能固着=只看通常功能，只有消极（功能上）。

口诀："疮变毒瘤"；培养"进个城"；环境"送烤鱼"；个性"废气剧毒"；课程"脑子散架"

问题解决与想象 P0

口诀："公鸡发情阉了"；培养"背萝莉洗发"；想象"想换斯文教官"

学习动机分类与奥苏贝尔成就动机 P0

马斯洛需要层次理论 P0

成就动机理论 P1

维纳成败归因理论 P0

因素内外稳定可控
能力内部稳定不可控

学习迁移 P0

德育概念与内容 P0

广义=社会+社区+家庭+学校德育；狭义=学校德育。内容（2017《中小学德育工作指南》）=社会主义核心价值观/中华优秀传统文化/理想信念/生态文明/心理健康教育。

德育过程四大基本规律 P0

本质=个体社会化和社会规范个体化统一。主要矛盾=社会要求与已有品德水平之间的矛盾。

  • ①多开端的知情意行培养过程：不一定从"知"开始，可从行/情/意开始

九大德育原则 P0

  • 导向性原则：坚持正确政治方向
  • 疏导原则：循循善诱以理服人，不粗暴压制
  • 尊重学生与严格要求相结合（严慈相济）：既尊重人格又严格规范
  • 教育影响一致性与连贯性：学校家庭社会统一，前后衔接
  • 因材施教原则：根据个性差异
  • 知行统一原则：理论与实践结合，说到做到
  • 正面教育与纪律约束相结合：既表扬鼓励又有纪律
  • 长善救失原则：发掘闪光点，用优点克服缺点
  • 集体教育与个别教育相结合（平行教育，马卡连柯）：依靠集体教育，同时个别谈心
口诀："叔向来言行一致，整钱财救急/导疏尊一因知正长集"

板块14：班级管理与班主任

群体与班级 P2

正式群体（按制度章程）vs非正式群体（自发形成，如兴趣小组）。"班级"一词最早由埃拉斯莫斯正式使用。

班集体发展阶段与标志 P1

阶段：①组建阶段（靠教师组织指挥）→②核心初步形成（班委会确定，班主任转指导）→③发展阶段（学生学会自我管理，班风舆论开始形成）→④成熟阶段（班干部各司其职，班风舆论最终形成）。

口诀：发展"组合战术"；特征"沐足鬼混"；目标+干部+班规+班风+活动

培养班集体方法 P0

①确定发展目标（动力）；②建立核心队伍；③制定规章制度纪律；④组织形式多样教育活动；⑤培养正确舆论和良好班风（重要标志）。

口诀："一起沐足鬼混做活动"

班级管理与课堂管理 P1

管理模式=常规/平行（马卡连柯）/民主/目标。课堂纪律：①教师促成；②集体促成；③任务促成；④自我促成（自律）——最高级。课堂气氛=积极/消极/对抗型。

口诀：自我促成=最高级；维持策略"老师发出女鬼尖叫声"

班主任工作内容 P1

  • ①了解和研究学生——前提和基础（观察法最基本/谈话法/书面材料分析/调查访问）
  • ②组织和培养班集体——中心工作/中心环节
  • ③建立学生档案
  • ④个别教育（优等生防骄傲/中等生促动力/后进生促转化）
  • ⑤组织班会课外活动
  • ⑥协调校内外教育力量
  • ⑦操行评定
  • ⑧工作计划与总结
口诀：了解学生是前提，组织班集体是中心；"纵火烧学生档案后集体跳槽"

后进生教育策略 P0

  • 关注学生阶段：关注学生个体差异——教师成熟的标志

P0 必考大题（必背）

1. 教学过程四大基本规律 简答/材料 P0

（1）间接经验与直接经验相统一（间接性规律）：学生以学习间接经验为主，学习间接经验要以直接经验为基础。

（2）掌握知识与发展能力相统一（发展性规律）：掌握知识是发展能力的基础，能力发展是掌握知识的重要条件，二者并非必然同步。

（3）教师主导与学生主体相统一（双边性规律）：教师在教学中处于组织者主导地位，学生是学习主体，要充分发挥学生主体性。
